codegraph-mcp — System Architecture

Read-only code dependency graph + semantic search for Rust codebases, served to AI agents over MCP, with a reinforcement loop that learns from agent feedback.

Clients & Access
EXTERNAL

opencode Agents

Any machine, any model. Calls the 16 MCP tools for PR review: blast radius, semantic search, diff analysis, feedback submission.

AUTH

Tailscale Funnel

https://tharun-pc…ts.net/mcp — public entry to the MCP server only. Constant-time bearer token check, per-IP rate limiting with lockout. Team members can also reach services directly over the tailnet.

AUTH

LAN / Tailnet

REST API :8000 (bearer token) and Grafana :3000 (admin login). Sign-up disabled; viewers are read-only.

Serving Layer
:8002

Stateless MCP Server

JSON-RPC over HTTP, survives client restarts. 14 read-only analysis tools + 2 feedback tools. Per-tool latency and call counters exported to Prometheus.

:8000

REST API (FastAPI)

Ingest triggers, build history, feedback evaluation, health. Bearer-token auth, rate limiting, request-size caps, trusted-host checks. All request latencies recorded in ms.

DAEMON

Reinforcement Agent

Every 5 min: quality-gates pending feedback (decision model), applies idempotent symbol boosts, refreshes gauges. Rerank refresh at 5 accepted, full rebuild at 10.

Storage & Indexing
SOURCE OF TRUTH

PostgreSQL

Index snapshots (chunks + graph edges), build registry (parent-chained), AI feedback, boost weights, email audit log. Everything else is derived and rebuildable from here + git.

DERIVED

Neo4j

Dependency graph, generation-tagged for zero-downtime swaps. Usage modes on USES edges (pattern_match, construction, trait_impl, …).

DERIVED

Weaviate

Vector search with shadow-collection swaps. 768-dim embeddings from BAAI/bge-base-en-v1.5 (t2v-transformers).

DECISIONS

Ollama — nimble 9B

Local decision model via /v1/systemone. Judges feedback content (specific / actionable / consistent) for the quality gate. ~30s/decision on CPU, async only, heuristic fallback.

CACHE

Redis

Rate limiting, build duration history, query stats, known MCP client IPs. All keys TTL'd (90d).

Ingestion: git repo → regex/tree-sitter extraction → snapshot in Postgres → graph (Neo4j gen swap) + semantic (Weaviate shadow swap) in parallel → cleanup old generations. Nightly sync via cron; incremental with blast-radius expansion; full rebuild fallback.

Observability — 10s resolution, 30-day retention
SCRAPE

Prometheus

Pull-only TSDB. Scrapes backend /api/metrics (bearer-injected), cadvisor, itself. Remote-write disabled, no host port.

LOGS

Loki + Promtail

Promtail tails all oncall-* container logs (docker_sd, 10s refresh) and pushes to Loki over the internal network. Push API not exposed.

CONTAINERS

cadvisor

Per-container CPU cores, memory, network. Read-only mounts, internal only.

:3000 EXPOSED

Grafana

The only exposed observability port. Dashboards: infra on top (RAM, CPU cores), then index freshness, build status, MCP calls/s + latency (ms), feedback gate. Admin + read-only viewers.
